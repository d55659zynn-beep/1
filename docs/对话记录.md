## 第一部分：电商小程序架构设计

### 用户

### 需求澄清（4 个问题与用户选择）

| 问题 | 用户选择 |
|---|---|
| 业务类型 | **电商 / 零售** |
| 后端方案 | **微信云开发**（免服务器、免域名备案、免 HTTPS 配置） |
| 技术栈 | **原生小程序**（性能最好、新能力支持最快） |
| 首版增长能力 | **全选**：社交裂变分享、订阅消息召回、公众号联动、搜索优化 |

### 方案要点

**1）技术选型决策**

- 渲染：原生 WXML/WXSS，核心长列表用 Skyline
- 后端：微信云开发（TCB）
- 状态：`app.globalData` + 页面级 `setData`，MVP 不引入 Mobx
- 组件：自研轻组件 + 按需引入 TDesign
- 红线：主包 ≤ 2MB（目标 1.5MB），总包 ≤ 20MB

**2）分包策略**

主包只放 tabBar 四页（首页 / 分类 / 购物车 / 我的），交易分包（商品详情 / 确认订单 / 支付结果 / 订单中心）通过 `preloadRule` 在首页后台预下载，营销分包（拼团 / 优惠券 / 海报 / 会员）按需加载。

```json
"preloadRule": {
  "pages/index/index": { "network": "all", "packages": ["trade"] }
}
```

**3）云数据库**：10 个集合 —— `users / products / skus / carts / orders / coupons / user_coupons / groupons / share_logs / config`，权限收敛到云函数，防越权。

**4）云函数**：`login / product / cart / order / pay / coupon / groupon / share / subscribe / admin` 共 10 个；支付回调必须验签，金额一律服务端计算。

**5）增长闭环五步**

流量进入 → 新客首单转化（新人券·首单立减·限时秒杀）→ 分享裂变（拼团·邀请有礼·分销海报）→ 订阅消息召回（发货·降价·券到期）→ 复购与会员（积分·会员等级·专属券），裂变带来的新客回流至入口形成循环。

**6）订阅消息授权时机**（转化率最高的三个点）

| 时机 | 模板 |
|---|---|
| 支付成功后 | 发货通知、物流提醒 |
| 参团成功后 | 成团通知、拼团失败退款通知 |
| 领券后 | 优惠券到期提醒（到期前 24h 定时触发） |

**7）性能预算**：主包 ≤1.5MB、冷启动首屏 ≤1.5s、单次 `setData` ≤256KB、列表分页 20 条 + 图片懒加载。

**8）审核避坑**：电商类目资质提前完善；不诱导分享；隐私指引与敏感 API 用途一致；分销只做一级。

**9）三周路线图**

- 第 1 周：骨架——环境、登录建档、商品/分类/详情/购物车、下单 + 微信支付打通
- 第 2 周：增长——新人券、拼团、分享归因 + 邀请有礼、三类订阅消息、sitemap + 公众号关联、简易运营后台
- 第 3 周：收口——性能优化、真机测试、隐私指引与类目资质、提审

## 第二部分：液态玻璃按钮复刻

### 用户

> https://github.com/CarGuo/gsy_flutter_demo/blob/master/lib/widget/liquid_glass_demo.dart 帮我按照这个做他的按钮

### 源码定位（关键发现）

1. 该路径 404；通过 GitHub 递归树 API 定位到真实文件在 **`lib/widget/canvas/liquid_glass_demo.dart`**。
2. 该文件是**全屏液态玻璃着色器**（`ui.FragmentProgram` + `liquid_glass.frag`，手指滑动扭曲背景图，iOS 26 风格），**里面没有按钮**。
3. 按钮实现在同目录 `glass_demo_page.dart` 的 `_buildGlassButton`：

```dart
Widget _buildGlassButton({required IconData icon, required VoidCallback onTap}) {
  return GestureDetector(
    onTap: onTap,
    child: Container(
      width: 60, height: 60,
      decoration: BoxDecoration(
        shape: BoxShape.circle,
        border: Border.all(color: Colors.white.withAlpha(55), width: 1),
      ),
      child: ClipOval(
        child: BackdropFilter(
          filter: ImageFilter.blur(sigmaX: 8, sigmaY: 8),
          child: Container(
            decoration: BoxDecoration(
              gradient: RadialGradient(colors: [
                Colors.white.withAlpha(75),
                Colors.white.withAlpha(25),
              ]),
            ),
            child: Icon(icon, color: Colors.white.withAlpha(220), size: 24),
          ),
        ),
      ),
    ),
  );
}
```

### 澄清与用户选择

| 问题 | 用户选择 |
|---|---|
| 落地方向 | **两个都要**：Flutter 组件 + 微信小程序自定义组件 |
| 按钮形态 | **带液态高光动效** |

### 实现要点

**Flutter**（`LiquidGlassButton`）

- `ClipOval` + `BackdropFilter(sigma 8)` 做真实背景模糊
- `SweepGradient` + `Transform.rotate` 实现液态高光扫过（比单层线性渐变更接近玻璃流体反光）
- 顶部 `FractionallySizedBox` 叠镜面反光增强立体感
- 按压缩放 0.92（`easeOutCubic`，160ms）
- 颜色统一用 ARGB 常量（如 `0x4DFFFFFF`），规避 `withOpacity` / `withValues` 的 SDK 版本差异
- 配套 `LiquidGlassBackdrop` 提供漂浮气泡

**微信小程序**（`liquid-glass-button` 自定义组件）

小程序 WebView 对 `backdrop-filter` 支持不稳定，做三层降级：

1. `.lgb__frost` —— `backdrop-filter: blur(Npx)`，iOS 等支持内核走真实背景模糊
2. `.lgb__blur` —— 背景图放大 2 倍后 `filter: blur(Npx)`，安卓兜底
3. 未传 `bgSrc` 时用半透明白色渐变兜底

按压缩放、动画时长用**内联 style** 控制，避开 WXSS CSS 变量在低版本 WebView 的兼容问题。

### 已知限制

- Skyline 渲染器不支持 `backdrop-filter`，页面需使用 WebView 渲染器
- 每个按钮是一个模糊图层，同屏建议 ≤ 8 个；长列表商品卡片改用静态半透明渐变
